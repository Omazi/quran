Third-party packages added to the app (npm dependencies)
========================================================

The repository keeps a NOTICE.txt beside each third-party content it holds (assets/fonts,
assets/data, assets/images/garden, tools/quran-data). npm packages live in node_modules, which
is not committed: this file records them, from the friends lot onward (QR code of invitation,
D36). Each licence was read in the package's own LICENSE file in node_modules after
installation, on 25 November 2026, not taken from the registry. Only permissive licences are
accepted (MIT, BSD, Apache-2.0).

Packages installed earlier are not listed here yet: to be completed (see the end of this file).

The Whisper model of the app (not an npm package; downloaded by the build, D42)
-------------------------------------------
File:     ggml-quran-tiny-q8_0.bin, 43,537,433 bytes, SHA-256
          ef01ab441b004f9e6f1ea98d397b43452b3a45efab7c3928ab37af655dde8b52
          (modules/voice-capture/voice-model.json). Copied into the app; not in the repository.
Model:    tarteel-ai/whisper-tiny-ar-quran, by Tarteel AI: OpenAI Whisper tiny fine-tuned on
          Quran recitation. Revision c3d7e624af5c81bef25a10a2af3a5a84cb4dd0f0.
Licence:  Apache License 2.0 (text: modules/voice-capture/MODEL-LICENSE.txt).
          Read in the LICENSE file of the repository that publishes the converted file
          (github.com/mano270699/watazawwadu-models) and, for the base model, in the NOTICE of
          a second, independent conversion (github.com/be2clack/sirat-models). The model card
          on huggingface.co could not be opened from the assistant's session (host refused):
          to be checked once by a person (D42).
Changes:  converted to GGML with whisper.cpp's models/convert-h5-to-ggml.py and quantized to
          q8_0 with whisper-quantize, by the publisher of the file; weights otherwise unchanged
          (its README). Apache-2.0 section 4 asks that the licence go with the model and that
          changed files say so: this entry and MODEL-LICENSE.txt do it in the repository; the app
          must show them too once it has a page of notices (see below).
Base:     openai/whisper-tiny, OpenAI: MIT (github.com/openai/whisper, LICENSE).

  Credit: the native microphone module (modules/voice-capture) follows the lessons written in
  expo-pcm-recorder (MIT, "Copyright (c) 2025-2026 Muhammed Durakovic",
  github.com/Tilawi/expo-pcm-recorder): the input format queried right before installing the
  tap, the sample rate converted by AVAudioConverter. No code of it is in the app.
