Third-party packages added to the app (npm dependencies)
========================================================

The repository keeps a NOTICE.txt beside each third-party content it holds (assets/fonts,
assets/data, assets/images/garden, tools/quran-data). npm packages live in node_modules, which
is not committed: this file records them, from the friends lot onward (QR code of invitation,
D36). Each licence was read in the package's own LICENSE file in node_modules after
installation, on 25 November 2026, not taken from the registry. Only permissive licences are
accepted (MIT, BSD, Apache-2.0).

Packages installed earlier are not listed here yet: to be completed (see the end of this file).
